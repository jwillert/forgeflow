# Test doubles: fake capability adapters, real SQLite in-memory for StateStore

`ForgeflowGateway` tests (`src/core/engine.test.ts`) exercise real orchestration logic against fakes for the Ports & Adapters capability interfaces (`PollingEventSource`, `WorkTracker`, `CodeHost`, `CodeReviewHost` — see `src/core/testing/fakes.ts`), but use the real `sqliteState` adapter pointed at `:memory:` for `StateStore` rather than a fake. We chose this split because GitHub/GitLab have no local-substitutable stand-in (a fake is the only option), while `better-sqlite3` already provides one for free — reimplementing its ordering/filtering semantics (claim-queued transaction, due-deferred cutoff, latest-failed-per-target lookup) as a hand-rolled fake would risk silently drifting from the real adapter and giving false confidence.
